Interactive Posters

Visual concept: Interactive 3D posters for The Animatrix.

3D posters

Website

Concept Idea

Each poster references images from the episodes and functions as both a button and a visual preview.

Animatrix is a 2003 animation project consisting of a series of short animated films, each offering a unique perspective on the world of The Matrix. I conceptualized my vision for the posters, demonstrated it with two examples, and designed a website to showcase them in a cohesive web space.

Posters Design

The idea for the poster frame was inspired by a book cover. I wanted the posters to share a common structure to conveniently place the text and button. I designed a uniform frame where elements extend outward, providing space for both the text and the button.

3D Posters

To create the posters, I used free, pre-existing 3D assets and modified them in Blender to meet my needs. The assets were created by:

Denis Cliofas

Jimmy Gunawan

Riysstech

Sololopenko

Website

Because the posters required significant attention, I opted for a minimalist design approach for the website. I envisioned selecting episodes as cards from a common stack.

Additionally, I thought it would enhance the user experience if the episodes played within the site itself, rather than redirecting to a third-party player.
